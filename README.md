# 鹈鹕骑车 🚲 · 3D Pelican Riding a Bicycle

A tiny Three.js scene: a helmeted pelican pedalling a bicycle around a looping road.

- Wheels spin, pedals turn and the legs follow (simple 2-bone IK)
- Drag to orbit the camera, scroll to zoom
- Single `index.html`, no build step — Three.js is loaded from a CDN

Live demo: https://cherylva9203.github.io/pelican-bike/
